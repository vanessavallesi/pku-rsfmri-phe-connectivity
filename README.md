## Overview

This repository provides the R code used to reproduce the statistical analyses reported in the manuscript. The analyses focus on the relationship between resting-state functional connectivity, concurrent phenylalanine levels, historical metabolic control, and cognitive performance in adults with early-treated classical phenylketonuria (PKU).

The manuscript uses data from the PICO study (*Phenylalanine and Its Impact on Cognition*), a randomized, double-blind, placebo-controlled cross-over trial. For the present analysis, only the cross-sectional baseline comparison between patients with PKU and healthy controls was used.
